# Cardinal3D
2023年1月9日至2023年3月17日在斯坦福大学CS248A课程项目。

This was a course project of CS248a taught at Stanford University during Jan. 9 2023 to Mar. 17 2023.

## 作业2 Assignment 2
### 实现功能 Functionalities：
	局部 Local:	
	面缩边 - FaceBevel
	边塌陷 - EdgeCollapse
	边翻转 - EdgeFlip
	边分离 - EdgeSplit
	塌陷边界边 - Collapsing a boundary edge
	分裂边界边 - Splitting a boundary edge
	擦除边 - EraseEdge
	全局 Global:
	三角剖分 - Triangulation
	线性细分 - LinearSubdivision
	Catmull-Clark细分 - CatmullClarkSubdivision
	简化 - Simplification
	
## 作业3 Assignment 3

### 实现功能 Functionalities：
```
生成相机射线 - Generating Camera Rays
射线与三角形相交 - Ray-Triangle Intersection
BVH相交 - BVH intersection
阴影射线 - Shadow Rays
带有俄罗斯轮盘赌的全局光线跟踪 - Global illumination path tracing with Russian roulette
完美镜面反射 - Perfect Mirror Reflection
```

## 自选期末项目 Self-Select Final Project
### 模拟真实相机效果 Simulate Realistic Camera Effects

### 实现的功能 Functionalities Implemented:
```
从虚拟固定尺寸传感器生成相机射线 Camera Rays from virtual fixed size sensor 
相机射线与镜头相交 Camera Ray-Lenses intersection
透镜聚焦效果，可调整照片的焦点 Lenses focusing effect to adjust focus point of photo
可调光圈的镜头 Adjustable Aperture of the Lenses
```
